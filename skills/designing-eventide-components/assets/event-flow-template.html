    How to read the panels

    • A lane is a stream. Pale lanes hold commands, solid lanes hold events, and each component has its own colour. Grey dashed lanes are outside the event store.
    • Time runs from left to right.
    • A solid arrow means the handler of this message writes that message.
    • A dashed arrow means a handler reacts to an event. It points at the event that is read.
    • A red title is a rejection. Grey attributes are optional.
    • A name above a grey box is a list. Each entry in the list has the attributes in the box.
    • Blue boxes are numbered notes.
