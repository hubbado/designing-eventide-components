The reply tells the reviewer that a stream which settles a customer's invoices
in one write holds the state of each of that customer's open invoices, and
that this can be thousands. It puts that size to the reviewer as a cost to
accept, or as a trade-off against a process across one stream for each
invoice.

A reply that recommends such a stream and does not name the size that it can
reach fails. A reply that recommends a process across one stream for each
invoice, and does not name its holds and releases, fails too.
